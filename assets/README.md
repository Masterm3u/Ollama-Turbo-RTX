# Demo assets

Drop your viral demo GIF here as **`demo.gif`** (ScreenToGif / Terminalizer / Windows Game Bar).

Suggested recording (15–25 seconds):

1. Open PowerShell **as Administrator**
2. Run: `irm https://masterm3u.github.io/turbo | iex`
3. Show the colored menu + ASCII banner
4. Press **[4]** and let the Stock | Speed | Context table finish
5. Export as GIF (~800–1200px wide, under ~8 MB for GitHub)

Once `assets/demo.gif` exists, the main README will show it automatically.
